# Théorie cinétique 

La Théorie cinétique des gaz est un modèle microscopique qui explique le comportement d’un gaz à partir du mouvement de ses molécules.

Elle dit que :

- Un gaz est constitué d’un très grand nombre de molécules.
- Ces molécules sont en mouvement permanent et désordonné.
- Elles se déplacent en ligne droite entre deux collisions.
- Les collisions sont élastiques.
- La pression vient des chocs des molécules contre les parois.

Elle permet d’expliquer :

- La pression
- La température (liée à l’énergie cinétique moyenne)
- La loi des gaz parfaits
- La distribution des vitesses (Maxwell-Boltzmann)

# Atome

Définition : la plus petite unité de matière qui conserve les propriétés chimiques d’un élément.

Composé de :

- Noyau : protons (+) + neutrons (0) c'est eux qu'on compte pour la masse, les électrons sont négligables
- Électrons (-) autour du noyau

Exemples : H (hydrogène), He (hélium), O (oxygène)

# Molécule

Définition : un ensemble de deux atomes ou plus liés chimiquement.

Les atomes peuvent être :

- Identiques → molécules diatomiques (O₂, N₂, H₂)
- Différents → molécules composées (H₂O, CO₂, NH₃)

# Rayon atomique vs rayon de covalence
- Rayon atomique: Distance approximative entre le centre du noyau et le bord du nuage électronique d’un atome isolé.

- Rayon de covalence: Distance approximative entre les centres de deux atomes liés dans une molécule.

# Gaz parfait

Un gaz parfait est un modèle idéal.

Il suppose que :

- Les molécules n’ont pas de volume propre (elles sont ponctuelles).
- Elles n’interagissent pas entre elles sauf lors de collisions.
- Les collisions sont parfaitement élastiques.

- Le gaz est peu dense

# Microscopique vs macroscopique
## Microscopique

On regarde les molécules individuellement.

On s’intéresse à :

- leur position
- leur vitesse
- leurs collisions
- leurs forces

Exemple :

- Une molécule d’air va à 500 m/s et frappe la paroi.


## Macroscopique

On regarde le gaz dans son ensemble, sans voir les molécules.

On parle de :

- pression
- température
- volume
- quantité de matière

Exemple :

- La pression du gaz est 1 atmosphère.

On ne regarde plus chaque molécule, seulement le comportement global.

La théorie cinétique relie les deux.

# Dans un gaz parfait

Chaque molécule est composée d’atomes très proches entre eux (liaisons covalentes).

La molécule est rigide et compacte, donc on peut la modéliser comme une sphère.

Les molécules elles-mêmes sont très éloignées les unes des autres, donc les interactions à distance sont négligeables.

Exemple : N₂, O₂, H₂, He (atomique)

Donc :

Molécule compacte = sphère.
Molécules éloignées = collisions rares → modèle gaz parfait.

# Dans un gaz réel / non parfait

Les molécules peuvent être plus grandes, non symétriques ou flexibles (rotation et vibration).

Les molécules peuvent avoir interactions attractives (liaisons hydrogène, dipoles…) avec les voisines.

Dans ce cas, la molécule n’est plus vraiment sphérique pour la simulation des collisions.

Exemple : H₂O (molécule angulaire), NH₃ (pyramide), CO₂ (linéaire mais rotations importantes)

Donc :

Molécule non sphérique → collisions plus complexes (rotation + vibration)
Interactions à distance → modèle sphères dures = approximation

# Pourquoi les molécules n’interagissent pas dans un gaz parfait

C’est une hypothèse du modèle, pas une loi physique :

- On suppose que les molécules n’ont pas de forces attractives ou répulsives à distance.
- Elles ne “se voient” pas tant qu’elles ne se touchent pas (collision).
- Les collisions sont instantanées et élastiques.

Pourquoi faire cette hypothèse ?

- Pour simplifier les calculs.
- Pour pouvoir relier les mouvements microscopiques aux grandeurs macroscopiques


# Gaz parfait = modèle idéal

- Un gaz parfait n’existe pas vraiment dans la nature.
- C’est un modèle théorique qui simplifie le comportement des gaz.

Dans la réalité, toutes les molécules interagissent un peu (Van der Waals, dipoles, liaisons hydrogène…).

# Quand le modèle est bon

Le gaz parfait est une très bonne approximation si :

- La densité est faible → les molécules sont très éloignées
- La température est suffisamment élevée → pas de condensation
- Les molécules sont petites et peu polaires → interactions faibles

Exemples :

- L’air dans une pièce → très proche d’un gaz parfait
- H₂, He, Ar → approximativement parfaits
- Vapeur d’eau près de la condensation → modèle moins valable
